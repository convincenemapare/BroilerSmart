# BroilerSmart 
An offline-first mobile application designed to empower small-scale broiler poultry farmers by eliminating internet dependency.

## Key Features
* **100% Offline Operation:** Complete database tracking running locally on-device—zero mobile data required.
* **Batch Management:** Seamlessly monitor bird counts, track daily mortality rates, and log growth cycles.
* **Financial Logging:** Easily record feed expenses, medication costs, and sales revenue directly from the field.
* **Performance Insights:** Immediate localized data summary to help farmers quickly understand true batch profitability.

## Tech Stack
* **Framework:** React Native (Expo)
* **Language:** TypeScript
* **Build Architecture:** Expo Application Services (EAS CLI)

## Roadmap & Future Upgrades
* **Phase 1 (Current MVP):** Core field deployment of independent Android APK to local farmers for live usability testing and data tracking.
* **Phase 2 (Upcoming V2.0):** Iterating on user feedback, optimizing database performance, and introducing advanced UI polishing (such as async submission loading indicators).
